# Lanework skills

A Lanework board is a folder of plain directories and Markdown files that the Lanework macOS app renders live. There is no API and nothing to sync, so an agent works a board by reading and editing its files, the same way its owner does through the app.

These skills teach an agent how to do that. They are published together as the `lanework` Claude Code plugin.

| Skill | What it is for |
|---|---|
| `lanework` | The base the others build on: what a board is, reading one, the write rules every board shares, and founding a new board. |
| `work` | Working a board: writing cards and comments, sweeps and triage, and farming work out to subagents. |
| `watch` | A standing watch on one or more boards, responding to changes as they arrive. |
| `discovery` | A guided examination of a project's problem and domain, run in rounds on a discovery board. |
| `plan` | Planning an idea too big for one session, one decision per ticket card. |
| `merge` | Resolving git conflicts on a board without a person. |
| `heal` | Bringing existing boards up to the current skills and guide. |

Install instructions are in the [README](https://github.com/laneworkapp/lanework-skills#readme).
