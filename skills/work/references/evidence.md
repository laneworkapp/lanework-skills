# Evidence

**Nearly every measurement trap fails toward a false zero or a false green**: the direction that reads as a pass.

**E0 first: before adding a check, name the wrong answer it would catch.** None → skip it. Procedures, not proof obligations; ceremony that couldn't change the verdict is cost.

| | rule |
|---|---|
| **E1** | **Population beside every delta and every zero.** "0 failures" means nothing without "over N tests in M suites". A right count over a slightly wrong population is the dominant failure. |
| **E2** | Would the check pass if the claim were **false**? Confirmatory ≠ discriminating. |
| **E3** | A load-bearing zero gets a **positive control in the same run**, differing in the measured dimension. A control returning the measurement's own number isn't one. |
| **E4** | **Status only from the work's own output**: the gate's success line, not absence of a failure line. Inferred from a path, flag or intent = not a status. |
| **E5** | Re-derive every figure received, the lead's included. "Diagnosis + prescribed edit" leaves only the edit evaluated; re-derive the diagnosis. |
| **E6** | Clean result → suspect the instrument before the artifact. |
| **E7** | Two signals sharing an input = **one** signal. Corroborate by varying a parameter the answer mustn't depend on. |
| **E8** | Pre-register the **observable** ("test X fails with Y"), not the channel ("the gate will be red"). |
| **E9** | Verify at the **sha the claim was about**. HEAD refutes a different claim. Never cite a line below an insertion point; name the site. |
| **E10** | **Read the hits, don't count them.** Surprising count → print the distribution. Empty distribution indicts the pattern, not the corpus. |
| **E11** | Retractions land in a **durable** artifact: code comment or card thread, never only a message. A deliberate absence gets a comment where someone would add it back. |
| **E12** | Check the fix for the defect class it fixed: the bug's shape recurs inside its own fix. |
| **E13** | Label every claim **measured**, **reasoned** or **inherited**. Adjudicate on labels, not seniority. |

## Measured, don't re-derive

- **A blocked subagent can fabricate a deliverable** (2026-08-29: a Bash-denied subagent returned an invented table). Numbers that must be right: produced in the main session or cross-checked against one independent value. **Numbers without raw output alongside = a claim.**
- Surprising commit or move → attribute before alleging (`companions.md`).
