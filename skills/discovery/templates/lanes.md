# Lanes

Read by `scripts/found-discovery-board.sh` (format: `lanework/templates/pipeline-lanes.md`). `collapsed`: `yes` starts collapsed. `body`: owner-facing lane policy, no `|`. A body's 2nd sentence = who acts + what starts it (`lanework/references/board-kinds.md`); `heal` reads it.

| order | title | collapsed | body |
|---|---|---|---|
| 1024 | Brief | | The two standing references. The agent rewrites the map at the close of each round, and a resuming session reads it first. The Topic card states the scope and what a shared understanding must cover. The Discovery map card is the outline of every decision, grouped by corner of the space. |
| 2048 | Facts | | One card per fact the agent established: from the code, the docs, the filesystem, a tool, or the web. The agent files each fact as it is established, unasked. The body is the fact and its source; the raw report is an attachment. A fact found wrong gets a dated correction comment, never an edit that hides the first reading. |
| 3072 | Asked | | One card per open question, filed by the agent, waiting on the owner. The owner answers by commenting on the card or by replying in chat, and only the agent moves a card out, once the ruling is written into the body. The body is the question, the options and the recommendation. |
| 4096 | Settled | | Answered questions. The agent moves a question here once the owner has ruled, and the body ends with a dated ruling in the owner's words. This lane is the design record: read it in order to see what was decided and why. A settled question is never edited; a change of mind is a new question in a later round that links this one. |
| 4608 | Decisions | | One card per ADR or PDR. The agent files it straight into this lane from a question's ruling, before the question settles. The title starts `ADR:` or `PDR:`, the `Record` and `Status` labels say which and whether it still stands, and line 1 of the body links the question it came from. Cards never leave this lane. A decision overturned keeps its card: it gets the `superseded` status and a dated comment linking its replacement, and the new card links it under Related. |
| 5120 | Parked | yes | Questions the owner deferred or declined, with the reason as the ruling. The agent moves a question here when the owner defers or declines it. Collapsed because it is read least; reopen one by asking it again as a new card that links this one. |
