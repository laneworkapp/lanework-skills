# Conduct

Base: `work/references/writing.md` for every comment, `lanework/references/writes.md` for every write. Discovery adds:

- **Body = full question; ask comment = where it's answered.** Exactly one ask per question card: the last comment when filed, handle on line 1. No other comment mentions the handle. Owner ruling, 2026-09-22 (first grill board): a question only in the body has nowhere to be answered.
- **Ruling = owner's words.** No paraphrase, and no recommendation passed off as accepted. "Yes" → "as recommended".
- **Settled bodies are append-only.** Never edit the question, options or recommendation.
- **One question per card, one decision per question.** Two decisions → two cards.
- **Facts cited, never asserted.** Name the source and attach the report. A question leaning on a fact links it.
